## 측정된 문제 (ko 기준 글자수)

소스 가이드 1,223자(첫 화면 전부 노출), 히어로 188자(+메타 3칩, 상단 ~25%),
골든 카드 상세(스탯 4칸+청취 포인트 3줄), 모드 탭 이름+설명 이중 표기.

## 결정 (4건)

1. **히어로 콤팩트화**: 부제·메타 칩 제거, 키커+한 줄 제목+언어 토글만
   (`player-hero--compact`). 텍스트 -70%.
2. **소스 가이드 접기**: `<details>` 래핑, 기본 접힘. summary 라벨
   `sourceGuide.toggleLabel` = "가이드 보기"/"Source guide".
3. **골든 카드 상세 접기**: 풀 카드의 스탯 dl + 청취 포인트 목록을
   `<details>`("상세"/"Details", `goldenListening.detailsLabel`)로. 제목·배지·
   실행 버튼은 유지. compact(확장) 렌더는 불변.
4. **모드 탭 설명 제거**: 탭 버튼은 이름만. 선택된 모드의 설명 한 줄을
   탭리스트 아래 캡션으로 표시.

## 테스트

- 기존 App 테스트 중 가이드 헤딩/메타 칩 가시성 단언을 새 구조로 갱신.
- 신규: 가이드 기본 접힘→토글로 펼침, 히어로 부제 부재, 모드 캡션 표시.
- `npm run qa` + `build:extension` + 실브라우저 스크린샷.
